# OmniHealth Profiler (全景健康数字孪生系统) - PRD

> 最后更新: 2026-06-11 | 开发进度: Phase 1 完成

## 1. 产品定位

一款基于 C++ 桌面端的个人全生命周期健康数据管理与智能分析引擎。

**核心价值主张**：让用户掌握自己的完整健康画像，通过本地私有化数据存储保障隐私，同时借助大模型能力获得专业级健康解读。

## 2. 目标用户

- 关注自身健康的个人用户
- 有慢性病管理需求（如高血压、糖尿病）的患者
- 需要长期追踪临床检验指标的亚健康人群

## 3. 核心功能需求

### 3.1 多源数据融合 ✅ (已实现)

支持录入多种健康数据类型，统一存储于本地 SQLite 数据库。

| 数据类别 | 示例指标 | 数据模型 | 状态 |
|---------|---------|---------|------|
| 基础体征 | 心率、步数、睡眠时长、体重、身高、腰围 | VitalsRecord | ✅ |
| 临床检验 | 空腹血糖、总胆固醇、LDL-C、HDL-C、甘油三酯、血尿酸 | LabTestRecord | ✅ |
| 血压专项 | 收缩压、舒张压 | BloodPressureRecord | ✅ |
| 用户档案 | 姓名、出生日期、性别、吸烟、地域、城乡、家族史、糖尿病 | UserProfile | ✅ |
| 病历摘要 | 既往病史、手术史、过敏史 | MedicalHistoryRecord | 📋 待实现 |

### 3.2 纵深算法评价 ✅ (核心算法已实现)

根据医学指南建立量化评价体系，提供长期的健康趋势分析。

- **心血管风险评估 (China-PAR)** ✅：整合年龄、性别、血压、血脂、腰围、吸烟、糖尿病、地域、城乡、家族史，计算 10 年 ASCVD 风险（五级分层：低危/临界/中危/高危/极高危）
  - 论文: Yang X, et al. *Circulation*. 2016;134:1430-1440
- **BMI 分级** ✅：自动计算 BMI + 五级分类（偏瘦/正常/超重/肥胖）
- **趋势分析** ✅：时间序列统计（均值/最小/最大/中位数/线性回归斜率）
- **健康报告生成** ✅：基于真实数据的文字摘要
- **代谢综合征诊断** 📋：待实现 (ATP III 标准)
- **血压分级** 📋：待实现 (ACC/AHA 2017)
- **eGFR 肾功能** 📋：待实现 (CKD-EPI 2021)

### 3.3 大模型私有顾问 📋 (接口已定义，实现待完成)

- LLMService 接口完整定义 (configure / chat / buildHealthContextPrompt)
- HealthManager::askHealthAdvisor 数据上下文注入已就绪

## 4. 技术选型依据

| 技术 | 选型理由 | 状态 |
|------|---------|------|
| C++17 | 高性能、跨平台，适合桌面端计算密集型场景 | ✅ |
| SQLite3 (Homebrew 3.53.2) | 嵌入式零配置，数据文件单文件便携，隐私友好 | ✅ |
| nlohmann/json (FetchContent v3.11.3) | 纯头文件 JSON 库，用于数据序列化与 API 交互 | ✅ |
| cpp-httplib | 纯头文件 HTTP 库，零依赖，适合 LLM API 调用 | 📋 |
| ImGui | 即时模式 GUI，与 C++ 原生集成无需中间层 | 📋 |
| CMake + FetchContent | 现代化构建系统，依赖管理简洁可靠 | ✅ |
