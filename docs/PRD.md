# OmniHealth Profiler (全景健康数字孪生系统) - PRD

## 1. 产品定位

一款基于 C++ 桌面端的个人全生命周期健康数据管理与智能分析引擎。

**核心价值主张**：让用户掌握自己的完整健康画像，通过本地私有化数据存储保障隐私，同时借助大模型能力获得专业级健康解读。

## 2. 目标用户

- 关注自身健康的个人用户
- 有慢性病管理需求（如高血压、糖尿病）的患者
- 需要长期追踪临床检验指标的亚健康人群

## 3. 核心功能需求

### 3.1 多源数据融合

除了基础体征（心率、步数），还支持录入临床检验（血糖、血脂、血压等）和病历数据。

| 数据类别 | 示例指标 | 来源 |
|---------|---------|------|
| 基础体征 | 心率、步数、睡眠时长、体重等 | 手动录入 / 穿戴设备同步 |
| 临床检验 | 空腹血糖、总胆固醇、LDL-C、HDL-C、甘油三酯、血尿酸等 | 手动录入检验报告 |
| 血压专项 | 收缩压、舒张压 | 手动录入 |
| 病历摘要 | 既往病史、手术史、过敏史、家族史等 | 手动录入 |

### 3.2 纵深算法评价

根据医学指南（如心血管风险评分）建立量化评价体系，提供长期的健康趋势分析。

- **心血管风险评估**：整合年龄、性别、血压、血脂、吸烟史等因素，计算 10 年 ASCVD 风险
- **趋势可视化**：每个指标的时间序列折线图，标注正常范围参考线
- **异常告警**：数值超出临床参考范围时标记醒目提醒
- **BMI 分级**：自动计算 BMI 并给出体重管理建议

### 3.3 大模型私有顾问

结合用户的本地健康数据库，生成带有本地数据的 System Prompt，通过外部 LLM API 提供个性化的健康建议与解读。

- **RAG 式上下文注入**：将用户的近期健康数据摘要作为 System Prompt 前置信息
- **API 适配层**：统一接口支持多种 LLM 后端（OpenAI / 本地 Ollama 等）
- **隐私优先**：敏感数据仅通过一次性 Prompt 传递，不持久化于服务器端
- **免责声明**：所有 AI 建议末尾附带"仅供参考，不构成医疗建议"

## 7. 技术选型依据

| 技术 | 选型理由 |
|------|---------|
| C++17/20 | 高性能、跨平台，适合桌面端计算密集型场景 |
| SQLite3 | 嵌入式零配置，数据文件单文件便携，隐私友好 |
| cpp-httplib | 纯头文件 HTTP 库，零依赖，适合 LLM API 调用 |
| ImGui | 即时模式 GUI，与 C++ 原生集成无需中间层 |
| CMake + FetchContent | 现代化构建系统，依赖管理简洁可靠 |
