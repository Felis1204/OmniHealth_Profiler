## 二、追问演示

### 追问1：「我应该怎么做才能把空腹血糖从7.5降到正常范围？」

**AI 回复要点（500+字）：**

- **核心认知**：问题本质是胰岛素抵抗，不是单纯"少吃"
- **进食顺序法**：纤维→蛋白质→主食，可削低餐后血糖峰值 40-50%
- **早餐重构**：戒粥/馒头，改2个水煮蛋+无糖豆浆+黄瓜
- **主食置換**：全天生重≤150g，一半换为抗性淀粉（冷却土豆、荞麦、燕麦米）
- **餐后运动**：三餐后30分钟内起身活动10-15分钟
- **每周2次抗阻**：深蹲、俯身划船、靠墙静蹲，增加肌肉耗糖
- **睡眠干预**：从6.4h延长至≥7.5h，降低皮质醇→降低空腹血糖
- **戒烟**：吸烟加重血管内皮损伤，戒烟24小时血压心率即开始改善
- **复诊建议**：2周后空腹血糖仍>7.0需就医启动药物（二甲双胍/SGLT-2抑制剂）

### 追问2：「血压偏高（146/91），有什么安全的运动方式？」

**AI 回复要点（400+字）：**

- **绿色安全区**：治疗性步行（30分钟不间断快走）、固定自行车、28-30℃水中行走
- **辅助运动**：靠墙静蹲、平板支撑（不憋气！）
- **红色禁区**：羽毛球/篮球（心率波动过大）、大重量举重（憋气致血压破200）、晨起空腹锻炼
- **心率靶点**：(220-60)×50~60% = **80~96 bpm**
- **水分**：高尿酸450→全天饮水≥2000ml，运动前后必须补水
- **足部保护**：糖尿病足部脆弱→专业运动鞋+运动后检查双脚
- **降压食谱**：下午4点/晚餐后1h → 热身5分钟 → 快走20分钟(心率80-96) → 靠墙静蹲2分钟×3组 → 拉伸5分钟

## 三、接口说明

### `follow_up_prompt` 是建议，不是预填

JSON 中的 `follow_up_prompt` 字段是 **AI 根据用户数据生成的追问方向建议**，展示在前端作为引导按钮或提示文字。**用户实际追问的内容完全由用户自己输入**，通过 `askFollowUp(question)` 发送。

```cpp
// 前端可以这样用:
// 1. 解析 JSON 中的 follow_up_prompt → 渲染为快捷提问按钮
// 2. 用户也可以自己在输入框打字
// 3. 调用 askFollowUp 发送
auto reply = mgr->askFollowUp(userInput);
```

### 追问的 System Prompt 已包含个性化约束

当前 `buildFollowUpSystemPrompt` 会把**完整健康数据上下文**作为 System Prompt 发给 AI，AI 天然会看到年龄、病史等。我会进一步强化个性化约束——明确要求 AI **不得推荐与用户年龄/病史/过敏史冲突的建议**。
