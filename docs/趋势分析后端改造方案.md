# 趋势分析后端改造方案 & 前端实现指南

> 目标：前端能够渲染每个关键指标在指定时间窗口（一周/一月/自定义）内的折线图，图表下方展示统计摘要。

---

## 一、现状分析

当前 `HealthManager.h` 中 `analyzeTrend` 的局限：

```cpp
// 当前接口 — 每个记录类型只返回一个默认指标的统计值，不返回数据点
TrendResult analyzeTrend(HealthRecordType type, TimePoint from, TimePoint to) const = 0;

struct TrendResult {
    double average, min, max, median, slope;  // 只有统计值，无时间序列数据点
};
```

**问题**：
1. 每种记录类型只分析一个默认列（如 `VITALS` → `heart_rate`，`LAB_TEST` → `fasting_glucose`），其他指标（体重、腰围、胆固醇等）被忽略
2. 只返回聚合统计值，没有时间-数值数据点，前端无法画图
3. 没有指标名称和单位信息，前端不知道自己在展示什么
4. 时间范围参数是 `TimePoint`（C++ `chrono::time_point`），前端用起来不方便

---

## 二、设计方案

### 2.1 新增数据结构（`backend/include/HealthManager.h` 或独立头文件）

```cpp
/// @brief 单个数据点（时间-数值对）
struct TrendPoint {
    std::string timestamp;   // ISO 8601 字符串，如 "2024-06-15T08:00:00Z"
    double value;            // 指标数值
};

/// @brief 单指标趋势序列 —— 前端用于绘制一条折线
struct MetricTrend {
    std::string metricName;               // 指标中文名，如 "收缩压"
    std::string metricKey;                // 指标键，如 "systolic"（前端可用于排序/匹配）
    std::string unit;                     // 单位，如 "mmHg"、"kg"、"mmol/L"
    std::vector<TrendPoint> dataPoints;   // 时间-数值数据点序列（按时间升序）

    // ---- 统计摘要（图表下方展示）----
    double average = 0.0;
    double min     = 0.0;
    double max     = 0.0;
    double median  = 0.0;
    double slope   = 0.0;    // 线性回归斜率（正=上升趋势，负=下降趋势）
    int    count   = 0;      // 数据点个数
};

/// @brief 完整趋势分析报告 —— 一个记录类型的所有指标趋势
struct TrendReport {
    HealthRecordType recordType;          // VITALS / LAB_TEST / BP
    std::string title;                    // 如 "体征指标趋势分析"
    std::string periodLabel;              // 如 "2024-06-01 至 2024-06-18"
    std::vector<MetricTrend> metrics;     // 每个可量化指标一条折线

    /// @brief 是否包含有效数据
    bool isEmpty() const { return metrics.empty(); }
};
```

### 2.2 新增 HealthManager 接口

```cpp
/// @brief 生成趋势分析报告（含时间序列数据点 + 统计摘要）
/// @param type 健康记录类型（VITALS / LAB_TEST / BP）
/// @param from 起始时间（nullopt 表示追溯到最早记录）
/// @param to   截止时间（nullopt 表示至今）
/// @return TrendReport，包含每个量化指标的折线数据与统计值
virtual TrendReport analyzeTrendReport(
    HealthRecordType type,
    std::optional<TimePoint> from,
    std::optional<TimePoint> to) const = 0;
```

### 2.4 后端实现核心逻辑（伪代码）

```cpp
TrendReport HealthManagerImpl::analyzeTrendReport(
    HealthRecordType type,
    std::optional<TimePoint> from,
    std::optional<TimePoint> to) const
{
    TrendReport report;
    report.recordType = type;

    // 1. 获取该记录类型的指标定义
    const auto& metricDefs = getMetricDefinitions(type);  // {列名, 中文名, 单位}
    if (metricDefs.empty()) return report;

    // 2. 确定表名和标题
    report.title = getReportTitle(type);

    // 3. 时间范围标签
    report.periodLabel = formatPeriodLabel(from, to);

    // 4. 对每个量化指标：
    for (const auto& def : metricDefs) {
        // a. 查询 (timestamp, col_value) 数据点
        //    SELECT timestamp, {col} FROM {table}
        //    WHERE {col} IS NOT NULL
        //      AND timestamp >= '{from}'
        //      AND timestamp <= '{to}'
        //    ORDER BY timestamp ASC
        auto rows = queryMetricPoints(table, def.column, from, to);
        if (rows.empty()) continue;  // 无数据则跳过该指标

        // b. 构建 MetricTrend
        MetricTrend mt;
        mt.metricName = def.label;
        mt.metricKey  = def.column;
        mt.unit       = def.unit;
        mt.count      = rows.size();

        // c. 填充数据点 + 计算统计值
        std::vector<double> values;
        for (const auto& [ts, val] : rows) {
            mt.dataPoints.push_back({ts, val});
            values.push_back(val);
        }

        mt.average = mean(values);
        mt.min     = *min_element(values);
        mt.max     = *max_element(values);
        mt.median  = median(values);
        mt.slope   = linearSlope(values);   // 复用已有的 linearSlope()

        report.metrics.push_back(std::move(mt));
    }

    return report;
}
```

### 2.5 时间范围工具（新增便利方法）

```cpp
// 在 HealthManager.cpp 中新增静态工具函数
static std::string formatPeriodLabel(
    std::optional<TimePoint> from,
    std::optional<TimePoint> to)
{
    std::string label;
    if (from) label += timePointToIso(*from).substr(0, 10);
    else      label += "最早记录";
    label += " 至 ";
    if (to) label += timePointToIso(*to).substr(0, 10);
    else    label += "最新记录";
    return label;
}
```

## 四、前端实现指南（供队友参考）

### 4.1 调用方式

```cpp
#include "HealthManager.h"

auto mgr = health::createHealthManager();

// 查询最近 30 天的血压趋势
auto now = std::chrono::system_clock::now();
auto monthAgo = now - std::chrono::hours(24 * 30);

health::TrendReport report = mgr->analyzeTrendReport(
    health::HealthRecordType::BP, monthAgo, now);

// 查询所有历史体征趋势
auto allVitals = mgr->analyzeTrendReport(
    health::HealthRecordType::VITALS,
    std::nullopt, std::nullopt);
```

### 4.2 数据绑定到 Qt Charts

```cpp
#include <QtCharts/QChartView>
#include <QtCharts/QLineSeries>
#include <QtCharts/QDateTimeAxis>
#include <QtCharts/QValueAxis>

// 为一个 MetricTrend 创建图表
QChart* createMetricChart(const health::MetricTrend& metric) {
    auto* series = new QLineSeries();
    series->setName(QString::fromStdString(metric.metricName));

    for (const auto& pt : metric.dataPoints) {
        QDateTime dt = QDateTime::fromString(
            QString::fromStdString(pt.timestamp), Qt::ISODate);
        series->append(dt.toMSecsSinceEpoch(), pt.value);
    }

    auto* chart = new QChart();
    chart->addSeries(series);
    chart->setTitle(QString::fromStdString(
        metric.metricName + " 趋势"));

    // X 轴 — 时间
    auto* axisX = new QDateTimeAxis();
    axisX->setFormat("MM-dd");
    axisX->setTitleText("日期");
    chart->addAxis(axisX, Qt::AlignBottom);
    series->attachAxis(axisX);

    // Y 轴 — 数值
    auto* axisY = new QValueAxis();
    axisY->setTitleText(QString::fromStdString(metric.unit));
    axisY->setLabelFormat("%.1f");
    chart->addAxis(axisY, Qt::AlignLeft);
    series->attachAxis(axisY);

    return chart;
}
```

### 4.3 展示统计摘要

```cpp
QString formatStats(const health::MetricTrend& m) {
    return QString(
        "均值: %1 %2 | 最小: %3 | 最大: %4 | "
        "中位数: %5 | 趋势: %6 | 数据点: %7")
        .arg(m.average, 0, 'f', 1)
        .arg(QString::fromStdString(m.unit))
        .arg(m.min, 0, 'f', 1)
        .arg(m.max, 0, 'f', 1)
        .arg(m.median, 0, 'f', 1)
        .arg(m.slope >= 0 ? "↑ 上升" : "↓ 下降")
        .arg(m.count);
}
```

### 4.6 时间窗口快捷方式

前端可以封装便利函数：

```cpp
// 获取最近 N 天的数据
auto weekReport  = mgr->analyzeTrendReport(type,
    now - 168h,  now);          // 7 天

auto monthReport = mgr->analyzeTrendReport(type,
    now - 720h,  now);         // 30 天

// 获取全部历史数据
auto allReport = mgr->analyzeTrendReport(type,
    std::nullopt, std::nullopt);
```

## 五、接口对比

| 维度 | 旧 `analyzeTrend` | 新 `analyzeTrendReport` |
|------|-------------------|------------------------|
| 返回指标数 | 1（默认列） | 全部可量化指标 |
| 数据点 | ❌ 不返回 | ✅ `vector<TrendPoint>` |
| 指标名/单位 | ❌ 无 | ✅ `metricName` + `unit` |
| 统计值 | `TrendResult`（5 字段） | 内嵌在 `MetricTrend` 中 |
| 多指标支持 | ❌ | ✅ `vector<MetricTrend>` |
| 前端可直接画图 | ❌ | ✅ 遍历 `dataPoints` 即可 |
